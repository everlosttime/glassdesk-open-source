# GlassDesk 1.7.1

## 固定桌面层与动态壁纸

- 修复部分 Windows 11 + Wallpaper Engine 环境下，固定桌面层的 Dock 和信息栏背景变黑的问题：兼容独立和嵌套的壁纸宿主，避免误读渲染子窗口的黑色画面。
- 实时采集不可用时，不再把动态壁纸背后的 Windows 壁纸底图误当成有效实时背景；改用半透明背景，采集恢复后自动恢复玻璃效果。
- 保留 Win+D 桌面层级、自动隐藏和防止自身画面进入玻璃背景的处理。
- 背景诊断增加实际选定壁纸窗口的类名和句柄，便于定位不同桌面结构的兼容问题。

## 精简安装包

- 安装包和便携包不再捆绑奶蛙运行组件及动画、声音资源，减少下载体积。

## 官网

- 官网部署包去掉固定版本号，首屏改为“免费使用”；之后发布新版本只需更新网盘安装包，无需重新上传网页。
- 下载保留夸克、百度两个网盘及公开源码入口；文件版本以分享页为准，无需新增版本接口或服务器配置。

保留 1.7.0 的 Dock 图标间距、桌面同步、启动台自动分组、Steam 图标修复和设备电量支持。

相关回归测试 111 项通过，包含本机 Windows 11 + Wallpaper Engine 的桌面归属测试及跨进程窗口结构测试。反馈机器的 Windows 11 具体版本、显卡驱动及壁纸组合尚待用户实测，不代表所有组合均已验证。

支持 Windows 10 2004（Build 19041）及以上、Windows 11 x64。升级前退出 GlassDesk，建议备份原安装目录旁的 Data 文件夹，再安装到原目录。
