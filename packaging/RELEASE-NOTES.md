# GlassDesk 1.6.0（草稿，暂不发布更新）

- 日历面板右上角新增“公历 / 农历”切换，自动保存选择；农历模式显示农历日期，并保留小号公历数字供对照，支持闰月。
- 修复键盘快捷键打开启动台时，页面容器出现整页虚线焦点框的问题，保留搜索、滚动与翻页操作。
- 关于页的“网盘下载”改为“下载入口”，点击仅显示官网二维码，可离线显示，扫码访问 https://glassdesk.cn/。点击外部或按 Esc 可关闭二维码。
- 保留信息栏外设电量选择与离线电量读取组件，可选择鼠标、耳机、键盘等摘要；具体支持取决于设备、连接方式和固件。
- 包含由 GlassDesk 设置管理、默认关闭的奶蛙回收站。
- 延续 1.5.11 的主屏壁纸读取优化，符合条件时只读取主屏所需范围。
- 包含 1.5.12 的玻璃滤镜采样范围优化，减少实时背景计算与临时内存分配，保持原像素输出和动态背景。

这是供手动测试的 GitHub 草稿，尚未正式发布，不触发客户端更新通知。官网 1.6.0 页面标记为“待上架”，网盘中的文件以实际分享页为准。

验证：日历及设置保存回归、启动台焦点样式与搜索翻页、竖屏主屏非激活预览、二维码独立解码，以及标准安装包自检。网友原机的快捷键触发场景仍需复测。
