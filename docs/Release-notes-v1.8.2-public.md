# GlassDesk 1.8.2 完整功能源码

本次同步 GlassDesk 1.8.2 发布版的产品实现和回归测试。仓库沿用现有分范围许可和第三方声明。

## 更新

- 修复固定桌面层下启动台翻页时玻璃背景突然停住的问题。动态背景在翻页期间持续更新，并减少了部分重复取帧等待。
- 启动台新增「自动移除失效的快捷方式」开关，默认关闭。开启后，启动台会移除反复确认目标已不存在的本地快捷方式。
- 「台前调度（测试版）」支持把窗口收纳到屏幕左侧，再点缩略图切回。默认按 Ctrl + Alt + J 选择窗口，右键缩略图可以把窗口加入当前组。本版改善了窗口切换和焦点恢复。
- 鼠标悬停时，缩略图会提亮并点亮边缘。左栏被窗口挡住时，可在屏幕左缘短暂停留来临时唤出。
- 设置的「快捷操作」补齐了说明图标，写明各项快捷键何时生效、如何使用和如何退出。

打包配置包含奶蛙运行组件。动画与声音素材由用户从官方 ZIP 导入。
