# GlassDesk 1.6.0 公开源码同步

从 1.6.0 产品提交同步 Dock、启动台、共享玻璃 / 原生渲染、附近传输与设置功能。包括键盘快捷键打开启动台时页面虚线框修复，以及关于页的单官网二维码入口。

继续保留无信息栏公开范围：移除信息栏、日历、控制中心、媒体 / 设备弹窗、相关系统状态和外设电量读取源文件；清理 AppHost 与设置绑定，并把模拟教学改为托盘菜单路径。共享 JSON 兼容字段保留，相关 UI 与数据读取实现不在本源码版中。

本次是有记录的公开版适配，不是与完整版本逐字节相同的源码或二进制。原许可文本与历史 Apache / 第三方权利保留，逐文件来源记录重新生成。没有合入私有 Git 历史或用户数据。

本次只更新源码仓库，不发布新的正式 Release，不修改客户端更新渠道。
