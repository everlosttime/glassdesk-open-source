# GlassDesk 1.4.0

2026-10-17 · 从公开版本 1.3.6 升级至 1.4.0，包含此前仅在私有仓库发布的 1.3.7 改进。

## 启动台文件夹

- 将一个应用图标停在另一个图标中心约 500ms，出现确认轮廓后松手即可合成文件夹；快速经过或移开会取消预览。
- 文件夹采用圆角磨砂玻璃外观，提供小图标预览与平滑展开、收起动画。
- 支持重命名、继续拖入、拖出、内部排序与滚动查看。只剩一个应用时自动解散，内容和布局持久保存。

## 拖动与启动体验

- 移除图标磁吸，降低交换、挤位排序的灵敏度，优先识别文件夹悬停；保留 Alt 排序、跨页拖拽和原有 Dock 操作。
- 修复从文件夹拖出后重复图标、持续拖动影响其他图标以及松手落点短暂跳到左上角的问题。
- 登录启动改用当前用户无延迟计划任务，减少进入桌面后的等待，保持普通权限；登记成功后迁移本安装的旧 Run 启动项，并保护其他副本的登记。
- 修复设置窗口“有时能拖、有时不能拖”：顶部标题和周围空白均支持拖动，滑块、按钮、分类与正文滚动保留各自操作。

## 自愿赞助

- 设置新增“赞助支持”，可选择支付宝或微信支付，点击旁边的“赞助”按钮后才会弹出对应收款码窗口。
- 使用作者提供的原始收款码，扫码后在手机端自定义金额，付款结果以支付宝或微信显示为准。
- 页面注明：“如果您觉得这款软件对您有帮助，可以自愿赞助支持开发”。
- **GlassDesk 免费提供全部功能。赞助完全自愿，不赞助也能使用全部功能，无需付费解锁。**

适用于 Windows 11 x64（Build 22000 及以上），自带 .NET 10 运行时。升级保留设置、应用库、文件夹、布局、自定义图标和登录启动配置。安装包不包含个人 Data；安装包未签名，可用同页 SHA256SUMS.txt 核对。
